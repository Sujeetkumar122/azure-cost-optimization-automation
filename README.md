# 💰 Azure Cost Optimization Automation

Simple and practical PowerShell and Azure CLI scripts to identify cloud waste and optimize Azure expenditure.

## 🚀 Key Scripts
- scripts/Get-UnattachedDisks.ps1 - Scans subscriptions for unattached managed disks that are incurring idle storage costs.
- Scheduled auto-start and auto-stop for non-production development VMs.
